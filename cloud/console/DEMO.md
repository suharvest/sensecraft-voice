# 🚀 SenseCraft Voice Web 演示说明

## 🎯 演示功能

### 1. 用户登录
- **功能**: 用户认证、路由保护、状态管理

### 2. 仪表盘
- **数据统计**: 录音数量、门店数量、点位数量、用户数量
- **增长趋势**: 本周录音增长趋势图表
- **活跃设备**: 今日活跃设备统计
- **最近活动**: 系统活动记录

### 3. 录音管理
- **数据展示**: 模拟录音记录列表
- **搜索过滤**: 按MAC地址搜索
- **分页功能**: 支持分页查询
- **状态管理**: 中间结果/最终结果标签
- **操作功能**: 查看详情、删除记录

### 4. 门店管理
- **数据展示**: 模拟门店列表
- **搜索功能**: 按名称、代码搜索
- **CRUD操作**: 新增、编辑、删除门店
- **状态管理**: 正常运营/暂停营业
- **表单验证**: 完整的表单验证规则

### 5. 响应式设计
- **桌面端**: 完整功能展示
- **平板端**: 适配中等屏幕
- **手机端**: 移动端优化

## 🎨 设计特色

### 主色调系统
- **主色**: #8CC020 (自然绿色)
- **辅助色**: 白色、浅绿色、深绿色
- **状态色**: 成功绿、警告橙、错误红

### 组件样式
- **卡片设计**: 圆角、阴影、悬停效果
- **按钮样式**: 主色调、悬停状态、过渡动画
- **表格样式**: 行悬停、状态标签、操作按钮
- **表单样式**: 输入框聚焦、验证提示

### 布局系统
- **侧边导航**: 可折叠、图标+文字
- **顶部导航**: 面包屑、用户菜单
- **内容区域**: 渐变背景、卡片布局
- **响应式网格**: 自适应列数

## 🔧 技术实现

### 前端架构
- **React 18**: 函数式组件 + Hooks
- **TypeScript**: 类型安全、接口定义
- **Ant Design**: 企业级UI组件库
- **Tailwind CSS**: 原子化CSS框架
- **Zustand**: 轻量级状态管理

### 数据管理
- **模拟数据**: 完整的演示数据集
- **API服务**: 统一的接口调用封装
- **状态管理**: 用户认证、应用状态
- **错误处理**: 统一的错误提示

### 路由系统
- **React Router 6**: 现代化路由管理
- **路由保护**: 认证状态检查
- **嵌套路由**: 布局组件嵌套
- **懒加载**: 页面组件按需加载

## 📱 使用说明

### 启动应用
```bash
npm run dev
```

### 访问地址
- **本地地址**: http://localhost:3000

### 功能导航
1. **登录页面**: 用户登录

3. **录音管理**: 管理录音记录
4. **门店管理**: 管理门店信息
5. **用户菜单**: 退出登录等操作

### 演示环境
- 使用模拟数据，无需后端服务
- 数据不会持久化保存

### 浏览器兼容
- 支持现代浏览器 (Chrome 90+, Firefox 88+, Safari 14+)
- 不支持IE浏览器
- 建议使用Chrome或Firefox

# 系统提示词管理器

## 功能概述

系统提示词管理器为AI分析页面提供了强大的角色管理功能，允许用户选择不同的AI角色来获得更专业的分析结果。

## 组件结构

### 1. SystemPromptSelector (系统提示词选择器)
- **位置**: AI分析页面顶部，清空按钮下方
- **功能**: 
  - 显示当前选择的AI角色
  - 快速切换不同的系统提示词
  - 打开系统提示词管理弹窗
  - 显示当前角色的详细信息

### 2. SystemPromptManagerModal (系统提示词管理弹窗)
- **触发**: 点击选择器中的"管理"按钮
- **功能**:
  - 查看所有系统提示词列表
  - 创建新的系统提示词
  - 编辑现有系统提示词
  - 删除系统提示词
  - 搜索和筛选提示词
  - 选择提示词应用到当前会话

## 使用方法

### 选择AI角色
1. 在AI分析页面顶部，找到"AI角色"选择器
2. 点击"选择角色"下拉按钮
3. 从列表中选择合适的AI角色
4. 系统会自动应用选择的角色到后续的AI对话中

### 管理系统提示词
1. 点击"管理"按钮打开管理弹窗
2. 在弹窗中可以：
   - 查看所有可用的系统提示词
   - 使用搜索功能快速找到特定提示词
   - 按角色或状态筛选提示词
   - 点击"选择"按钮应用提示词
   - 点击"新建提示词"创建自定义角色

### 创建自定义角色
1. 在管理弹窗中点击"新建提示词"
2. 填写以下信息：
   - **名称**: 角色的名称（如"数据分析师"）
   - **角色**: 系统角色类型（system/assistant/user）
   - **内容**: 详细的角色描述和指令
   - **标签**: 用逗号分隔的标签，便于分类
   - **激活状态**: 是否立即激活使用
3. 点击"保存"完成创建

## 预设角色类型

### 1. 数据分析师
- **用途**: 从录音数据中提取关键信息、识别趋势模式
- **特点**: 数据驱动，提供量化洞察

### 2. 业务顾问
- **用途**: 识别业务机会、客户需求、服务改进点
- **特点**: 商业角度分析，提供实用建议

### 3. 技术专家
- **用途**: 分析设备性能、音频质量、系统稳定性
- **特点**: 技术角度分析，提供优化建议

### 4. 客服质量评估员
- **用途**: 评估服务态度、沟通技巧、问题解决能力
- **特点**: 服务质量分析，提供改进建议

## 技术特性

### 智能推荐
- 系统会根据录音数据特征自动推荐合适的AI角色
- 基于录音数量、时间范围、设备分布等特征进行推荐

### 上下文感知
- 选择的系统提示词会自动注入到AI对话中
- 提供更专业、更针对性的分析结果

### 实时切换
- 可以在对话过程中随时切换AI角色
- 切换后立即生效，无需重新开始对话

## API集成

系统提示词管理器集成了完整的CRUD API：

- `GET /api/v2/openai/system-prompts` - 获取提示词列表
- `POST /api/v2/openai/system-prompts` - 创建新提示词
- `PUT /api/v2/openai/system-prompts/{id}` - 更新提示词
- `DELETE /api/v2/openai/system-prompts/{id}` - 删除提示词

## 样式定制

组件支持响应式设计，在移动端和桌面端都有良好的显示效果。可以通过修改 `SystemPromptManager.css` 文件来自定义样式。

## 注意事项

1. 系统提示词会在每次AI对话时自动注入
2. 建议保持提示词内容简洁有效，避免影响对话效果
3. 删除提示词前请确认没有正在使用的会话
4. 建议保留一个名为"default"的激活提示词作为默认选项

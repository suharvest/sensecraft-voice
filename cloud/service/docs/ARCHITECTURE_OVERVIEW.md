## 🏗️ 核心模块

### 1. 录音管理 (Recording)
- **WebSocket流式输入**: 实时接收语音识别数据
- **HTTP POST接口**: 批量提交录音数据
- **数据存储**: 支持中间结果和最终结果
- **查询功能**: 多条件查询和分页

### 2. 设备管理 (Device)
- **设备注册**: 设备信息管理
- **状态监控**: 设备在线状态
- **分配管理**: 设备分配到点位
- **关联查询**: 设备与门店/点位关联

### 3. 门店点位 (Store & Location)
- **层级管理**: 门店 → 点位 → 设备
- **CRUD操作**: 完整的增删改查
- **关联关系**: 自动维护关联关系
- **查询优化**: 支持多维度查询

### 4. 聊天对话 (Chat)
- **会话管理**: 聊天会话创建和管理
- **AI集成**: 与Dify API集成
- **流式响应**: 支持流式对话
- **外部集成**: Seeed API集成

### 5. 用户管理 (User)
- **用户认证**: 注册、登录、权限控制
- **密码管理**: 安全的密码存储
- **会话管理**: 用户会话维护

## 🔄 数据流示例

### 录音数据流
```
客户端 → WebSocket/HTTP → Router → Controller → DAO → Database
  ↑                                                      ↓
  └─────────────── 确认响应 ←─────────────────────────────┘
```

### 聊天对话流
```
用户 → 客户端 → 服务端 → Dify API → 流式响应 → 存储 → Seeed API → 返回
```

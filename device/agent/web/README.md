# 语音识别系统前端页面

## 功能特性

### 1. 首页 - 实时语音对话
- **对话形式展示**：采用现代化的对话界面，每条语音识别结果以对话气泡形式显示
- **最多20条记录**：自动维护最新的20条对话记录，超出时自动滚动
- **说话人信息**：
  - 个性化头像（基于speaker_id中的数字，如speaker_05显示为"5"）
  - 说话人ID和姓名
- **对话内容**：清晰显示识别的文本内容
- **元数据展示**：
  - 时间戳（本地化显示）
- **实时更新**：WebSocket连接后自动接收和显示新数据
- **自动连接**：页面打开后自动连接WebSocket，无需手动操作
- **交互功能**：
  - 清空对话记录
  - 自动重连机制（最多5次重试）

### 2. 设备状态 - 系统监控
- 实时显示系统资源使用情况：
  - CPU使用率
  - 内存使用量
  - 剩余录音时长（基于可用磁盘空间计算）
- 设备信息：
  - MAC地址
  - IP地址
  - 软件版本
- 远程连接：
  - 远程服务地址（从配置文件获取）
  - 连接状态显示
  - 一键测试连接功能（支持404状态码，表示网络可达）
- 自动刷新（每30秒）
- 支持手动刷新

## 技术实现

### WebSocket连接
- 连接地址：`ws://127.0.0.1:8090/v1/voice/asr-ws`
- **自动连接**：页面加载完成后自动建立连接
- 自动解析JSON消息格式
- 实时更新对话记录
- 智能重连机制

### HTTP API调用
- 设备状态接口：`http://localhost:8090/v1/voice/device/status`
- 使用Fetch API进行异步请求
- 错误处理和用户提示

### 对话管理
- 使用数组管理对话历史
- 自动限制最大记录数（20条）
- 新记录插入到顶部
- 支持清空操作

### 头像生成逻辑
- 从`speaker_id`字段提取数字
- 支持格式：`speaker_XX`（XX为数字）
- 提取失败时显示"?"作为默认头像

### 响应式设计
- 支持桌面和移动设备
- 现代化UI设计
- 流畅的动画效果
- 自定义滚动条样式

## 使用方法

1. **启动服务器**：运行 `./start_server.sh` 或直接访问 `http://localhost:8090`
2. **自动连接**：页面打开后自动连接WebSocket，开始接收语音识别数据
3. **查看对话**：语音识别结果会自动以对话形式显示，最多保存20条
4. **管理对话**：可以手动清空对话记录
5. **监控状态**：切换到"设备状态"标签页查看系统运行状态
6. **演示功能**：访问 `demo_conversation.html` 体验对话界面效果

## 注意事项

- 确保服务器在8090端口运行
- WebSocket服务需要正常运行
- 设备状态API需要可访问
- 建议使用现代浏览器以获得最佳体验
- 对话记录仅在当前会话中保存，刷新页面后会清空
- 最多显示20条对话记录，超出时自动滚动
- 页面打开后会自动尝试连接WebSocket，无需手动操作
